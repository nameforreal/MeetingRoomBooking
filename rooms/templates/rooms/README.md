
# MeetingRoomBooking

Веб-приложение для бронирования переговорных комнат.

## Технологии

- Python 3.14
- Django 6.0
- SQLite (временная база для разработки)
- HTML, CSS
- Git

## Реализованные функции

- Регистрация и авторизация пользователей
- Просмотр переговорных комнат
- Бронирование на 1–4 часа
- Проверка пересечений бронирований
- Просмотр истории бронирований
- Отмена бронирований
- VIP-заявки с подтверждением администратора
- Административная панель Django

## Запуск проекта

Установить зависимости:

    pip install -r requirements.txt

Применить миграции:

    python manage.py migrate

Запустить сервер:

    python manage.py runserver 8001

Адрес приложения:

http://127.0.0.1:8001/
