# Обновление личного кабинета MeetingRoomBooking

## Что добавлено
- Отдельный раздел «Профиль»: редактирование имени, фамилии и электронной почты.
- Раздел «Мои встречи»: статистика, фильтры по статусам, поиск по названию комнаты.
- Страница подробностей каждого бронирования.
- Изменение даты и времени существующего бронирования с повторной серверной проверкой конфликтов.
- Быстрые действия из списка встреч и страницы подробностей.
- Проверка владельца на сервере: пользователь не может просматривать или редактировать чужое бронирование.
- Адаптивная верстка и поддержка существующих светлой/тёмной тем.
- Добавлены тесты основных сценариев кабинета.

## Установка
1. Остановите Django-сервер (`Ctrl+C`).
2. Сделайте резервную копию своего `db.sqlite3` и файла `.env`.
3. Распакуйте архив поверх копии проекта или замените файлы проекта содержимым архива.
4. **Не удаляйте и не заменяйте свой `db.sqlite3` и `.env`.** В архиве база данных намеренно не включена.
5. Активируйте виртуальное окружение и выполните:
   ```powershell
   python manage.py check
   python manage.py test
   python manage.py runserver
   ```
6. Проверьте страницы:
   - `/my-bookings/`
   - `/profile/`
   - откройте конкретную встречу через «Подробнее»
   - `/admin/` для проверки, что административная часть осталась доступна.

## Важные замечания
- Изменение бронирования доступно только владельцу, пока встреча не отменена и ещё не завершилась.
- При сохранении времени используется существующая модель `Booking` и её валидация длительности/конфликтов.
- Изменение данных профиля не меняет имя пользователя и пароль.
- Смена пароля, аватар, уведомления и интеграции календаря пока не реализованы.
- Django и REST API не переписывались в этом обновлении.
- Тесты не были исполнены в среде сборки, поскольку в ней не установлены зависимости проекта; перед сдачей запустите `python manage.py test` в своём виртуальном окружении.
