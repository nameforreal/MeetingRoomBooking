# Установка панели управления
1. Остановите Django через Ctrl+C и сделайте резервную копию проекта и базы данных.
2. Распакуйте архив в корень проекта рядом с manage.py, сохраняя структуру каталогов.
3. Не заменяйте .env, базу данных, фотографии и миграции.
4. Выполните:

```powershell
python manage.py check
python manage.py test rooms dashboard management
python manage.py runserver 8001
```

Откройте http://127.0.0.1:8001/management/. Доступ только для пользователей с is_staff=True. Создание и изменение комнат и аккаунтов выполняется через стандартный Django Admin. Изменений моделей и миграций нет.
