# MeetingRoomBooking — расширенная панель управления

## Новое
- Управление переговорными непосредственно в `/management/rooms/`: создание, редактирование, включение/отключение, загрузка фотографии до 5 МБ.
- Загруженные фотографии отображаются в каталоге, на главной и в карточке помещения; старые фотографии остаются запасными.
- Управление пользователями через `/management/users/`: редактирование профиля, роли сотрудника и активности доступно **только суперпользователю**.
- Аналитика `/management/analytics/`: фильтр периода (до 366 дней), показатели и график по фактическим заявкам.
- Стандартная Django Admin сохранена.
- Дополнительные автоматические тесты.

## Установка
1. Сделайте резервную копию текущего проекта и базы данных.
2. Распакуйте архив в корень проекта с заменой файлов. **Не удаляйте** `.env`, существующую БД и загруженные изображения из `media/`.
3. В активированном `.venv`: `pip install -r requirements.txt` (добавлена Pillow).
4. `python manage.py check`
5. `python manage.py migrate` (добавляется только необязательное поле фотографии Room.photo).
6. `python manage.py test`
7. `python manage.py runserver`

**Важно:** при `DEBUG=False` раздачу `/media/` нужно настроить через веб-сервер. Резервная копия медиафайлов должна храниться вместе с резервной копией БД. Для боевого развертывания нужны отдельные настройки безопасности.

## Проверки
- Сотрудник создаёт и отключает переговорную, обычный пользователь не имеет доступа.
- Суперпользователь редактирует роли, сотрудник не может менять права пользователей.
- Загруженное фото появляется в каталоге.
- Существующие бронирования и API остаются доступными.
