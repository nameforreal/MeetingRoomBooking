# MeetingRoomBooking — Enterprise UI Update

Основа: архив MeetingRoomBooking(3).zip (многостраничная версия). Обновление также включает функции из Enterprise Patch 1, поэтому устанавливать предыдущий патч отдельно не нужно.

## Установка
1. Остановите сервер Django (Ctrl+C).
2. Сохраните резервную копию проекта и базы PostgreSQL.
3. Распакуйте **содержимое** архива в корень проекта (рядом с manage.py), с заменой совпадающих файлов.
4. Убедитесь, что активировано виртуальное окружение и контейнер PostgreSQL запущен.
5. Выполните `python manage.py check`, `python manage.py test`, `python manage.py migrate --check`.
6. Запустите `python manage.py runserver 8001`.
7. Проверьте `/dashboard/`, `/schedule/`, `/rooms/`, `/register/` и обе темы. Обновите браузер Ctrl+F5.

## Изменения
- Новое приложение dashboard с реальными запросами к Room и Booking.
- Расписание с датой, фильтром помещения и переходом к бронированию.
- Рабочая панель со статистикой пользователя и таблицей встреч.
- Переработанная корпоративная стилистика и анимации с поддержкой reduced motion.
- Русский язык интерфейса Django, сохранён исходный часовой пояс UTC.
- Обновлённые формы регистрации и тесты из предыдущего Enterprise Patch 1.

## Ограничения
- Время в расписании отображается с 08:00 до 20:00 по локальному времени Django.
- Нажатие свободной ячейки открывает форму бронирования на выбранную дату; час выбирается в форме.
- Интеграции Outlook/Google, QR check-in и планы этажей НЕ реализованы.
- Модели и миграции не изменены, данные не удаляются.
- Python синтаксически проверен; Django тесты следует выполнить локально.
