# REST API MeetingRoomBooking

Базовый адрес: `/api/`. Формат обмена — JSON. Для запросов, изменяющих данные, используйте авторизованную Django session (и CSRF-токен при cookie-аутентификации).

## Переговорные

- `GET /api/rooms/` — список активных комнат.
- `GET /api/rooms/{id}/` — сведения о комнате.
- `POST /api/rooms/` — создать комнату (только сотрудник с правом staff).
- `PUT/PATCH /api/rooms/{id}/` — изменить комнату (только staff).
- `DELETE /api/rooms/{id}/` — архивировать комнату (только staff; исторические бронирования сохраняются).
- `GET /api/rooms/{id}/availability/?date=YYYY-MM-DD` — занятые интервалы на выбранную дату. Возвращаются только время начала и окончания, без личных данных участников.

Список, сведения и свободные интервалы комнат доступны без авторизации. Изменение каталога разрешено только сотрудникам со статусом `is_staff`.

## Бронирования (только авторизованный пользователь)

- `GET /api/bookings/` — только собственные бронирования.
- `GET /api/bookings/{id}/` — подробности собственного бронирования.
- `POST /api/bookings/` — создать бронирование.
- `PUT /api/bookings/{id}/` — полностью изменить дату, время и/или комнату (для PUT нужны все обязательные поля).
- `PATCH /api/bookings/{id}/` — частично изменить дату, время или комнату.
- `POST /api/bookings/{id}/cancel/` — отменить предстоящую встречу.

Поля создания/изменения:

```json
{
  "room": 1,
  "start_time": "2026-12-01T10:00:00+03:00",
  "end_time": "2026-12-01T12:00:00+03:00"
}
```

`status`, `user` и `created_at` нельзя менять через API. Стандартные комнаты подтверждаются автоматически, VIP-бронирования создаются со статусом ожидания. Проверяются доступность комнаты, длительность 1–4 часа, время в будущем и пересечение с другими активными бронированиями.

### Фильтры списка бронирований

- `?status=pending|confirmed|cancelled`
- `?period=upcoming|past`
- `?room=ID`
- `?date_from=YYYY-MM-DD&date_to=YYYY-MM-DD`
- `?ordering=start_time|-start_time|created_at|-created_at`

Пример: `/api/bookings/?period=upcoming&status=confirmed&ordering=start_time`.

## Коды ответов

- `200` — успешно;
- `201` — ресурс создан;
- `400` — неверные данные, конфликт времени или недопустимая операция;
- `401/403` — требуется авторизация или недостаточно прав;
- `404` — объект отсутствует или не принадлежит текущему пользователю.

## Администрирование

Управление комнатами и всеми бронированиями выполняется через `/admin/` пользователями с соответствующими правами Django Admin. Для бронирований доступны фильтры, поиск, подтверждение и отклонение ожидающих заявок, а также экспорт выбранных записей в CSV.
